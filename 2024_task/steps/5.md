提交时请将每道题目对应的文件名命名为 `2-xx.ts` 的形式，如 `2-1.ts`。

#### 1

```javascript
// 请补全参数类型和返回类型

  return a + b;
}
```

#### 2

```typescript
type Fn = any;  // 请补全函数类型

```
