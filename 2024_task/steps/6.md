# Node.js 入门

## 学习目标

- 掌握 Node.js 的常用模块
- 能够使用 npm 和/或 yarn 等包管理器进行包管理

## 作业

在本阶段的作业中，我们将常用场景抽象为了两个实际的小任务：一个是 Node.js 脚本编写，对应了本次的爬虫任务；另一个则是 Node.js 搭建 HTTP 服务器，对应了本次的 Koa HTTP Server 任务。

### 一、Web Spider

#### 作业要求

爬取「福州大学通知文件系统」上今年 1 月 1 日到现在的所有通知的发表日期、部门、标题、访问链接。

网址: <https://info22.fzu.edu.cn/lm_list.jsp?wbtreeid=1460> (需要校园网环境)

- 使用 Node.js 的 fetch API 或者第三方库（如 axios）进行网页请求。
- 使用 Cheerio 解析 HTML 内容，并利用适当的 CSS 选择器来获取所需信息。
- 将爬取到的数据存储到本地文件 `notices.json` 中（无需上传到 GitHub，但需要体现存储过程）。
- 提交代码时，确保包含一个说明文件，包含如何运行爬虫的指南以及爬取结果的数据字段说明。

#### Bonus

- 使用并发请求提升爬取速度，并使用诸如 p-queue 等库来控制并发请求数量，避免对服务器造成过大压力。
- 爬取每个通知的正文及访问人数，并将其存储在 `notices.json` 中的每个通知对象中。
- 将爬取的数据存储到 SQLite、MySQL、MongoDB 或其他数据库中（任选一个），并提供相应的查询接口。可以使用 ORM 框架（如 Sequelize 或 Mongoose）来简化数据库操作。

### 二、Simple HTTP Server

#### 作业要求

使用 Koa 搭建一个简单的 HTTP 服务器，利用 Node.js 的 fs 模块提供以下 API：

- 上传文件 `/api/upload`：接收文件上传，并将文件保存到服务器的 `uploads` 目录下。
- 删除文件 `/api/delete`：接收文件名参数，删除服务器 `uploads` 目录下对应的文件。
- 列出文件 `/api/files`：返回服务器 `uploads` 目录下的所有文件列表。

同时编写一个静态的 HTML 页面，提供一个简单的前端界面，允许用户进行文件上传、获取文件列表等操作，并获取上传后的访问 URL。放置在合适的目录下，并配置 Koa 服务器提供静态文件服务。

#### Bonus

- 增加鉴权功能，只有登录用户才能进行文件上传和删除操作。
- 思考如何解决文件名冲突问题，采用合适的方式来生成唯一文件名。
- 将上传的文件信息存储到数据库中（如 SQLite、MySQL 或 MongoDB， ~~甚至可以是本地 JSON 文件~~ ）。
