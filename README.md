# 西二在线前端学习资料（2026 版）

这里是西二在线工作室前端方向的学习与考核指南，旨在为初学者提供一个循序渐进的前端学习路线。在完成每个阶段的学习任务后，都会布置相关作业以供练习。

## 概览

说明：预期时长以一名零基础全日制大学生为参考，如果是全身心投入学习，或者已经对其他语言有一定的了解，每一阶段所需的时间会比预期时长来的短。

| 阶段                                     | 内容                                                                                                             | 预期时长 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------- |
| [项目一：个人博客](./steps/1.md)         | HTML 语义化标签、CSS 布局与动画、JavaScript DOM 操作、响应式设计、本地存储                                       | 3-4 周   |
| [项目二：b站鬼畜实验室web](./steps/2.md) | React 组件化、TypeScript 类型系统、Vite 构建链路、Node.js 后端开发、Puppeteer 爬虫、ECharts 数据可视化、部署上线 | 4-5 周   |
| [项目三：摸鱼养鱼 App](./steps/3.md)     | React Native 跨端开发、Zustand 状态管理、Firebase 云端数据同步、JWT 用户认证、实时排行榜、APK 打包分发           | 4-5 周   |

## 学习目标

我们的目标是快速为初学者构建一套从零到上线的完整知识体系。通过三个递进式项目，让学员逐步掌握前端基础、全栈开发和跨端应用开发，最终具备独立完成一个完整项目的能力。

三个项目的定位如下：

| 项目                   | 定位     | 解决的问题                                          |
| ---------------------- | -------- | --------------------------------------------------- |
| 项目一：个人博客       | 前端基础 | 学会 HTML/CSS/JS，理解网页是怎么构成的              |
| 项目二：鬼畜热梗实验室 | 全栈进阶 | 学会 React + Node.js + 爬虫，理解前后端如何协作     |
| 项目三：摸鱼养鱼 App   | 跨端设计 | 学会 React Native + 云端，理解 App 如何从开发到上架 |
