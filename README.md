# 西二在线前端学习资料（2026 版）

这里是西二在线工作室前端方向的学习与考核指南，旨在为初学者提供一个循序渐进的前端学习路线。在完成每个阶段的学习任务后，都会布置相关作业以供练习，2024版考核请在 ./2024_task 处查看。

## 概览

说明：预期时长以一名零基础全日制大学生为参考，如果是全身心投入学习，或者已经对其他语言有一定的了解，每一阶段所需的时间会比预期时长来的短。

| 阶段                                          | 内容                                                                                                                           | 预期时长 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------- |
| [项目一：个人博客](./steps/1.md)              | HTML 语义化标签、CSS 布局与动画、JavaScript DOM 操作、响应式设计、本地存储                                                     | 3-4 周   |
| [项目二：B站鬼畜区数据分析看板](./steps/2.md) | React/Vue 二选一、TypeScript 类型系统、Vite 构建链路、Node.js + Express 后端、axios/cheerio 爬虫、ECharts 数据可视化、部署上线 | 4-5 周   |
| [项目三：热点创意工坊](./steps/3.md)          | 多 Agent 协作、爬虫采集、Tool Calling 标准化、SQL 持久化、前端创意看板、Human-in-the-Loop                                      | 4-5 周   |

> 项目三 3.md 末尾还包含一个**隐藏选做项目**，涉及 React Native + Expo、TypeScript、AsyncStorage、腾讯云开发、APK 打包，感兴趣的同学可继续挑战。

## 学习目标

我们的目标是快速为初学者构建一套从零到上线的完整知识体系。通过三个递进式项目，让学员逐步掌握前端基础、全栈开发和跨端应用开发，最终具备独立完成一个完整项目的能力。

三个项目的定位如下：

| 项目                          | 定位     | 解决的问题                                          |
| ----------------------------- | -------- | --------------------------------------------------- |
| 项目一：个人博客              | 前端基础 | 学会 HTML/CSS/JS，理解网页是怎么构成的              |
| 项目二：B站鬼畜区数据分析看板 | 全栈进阶 | 学会 React/Vue + Node.js + 爬虫，理解前后端如何协作 |
| 项目三：热点创意工坊          | 多 Agent | 学会多 Agent 协作、工具调用、SOP 编排               |
| 隐藏项目：摸鱼养鱼 App        | 跨端设计 | 学会 React Native + 云端，理解 App 如何从开发到上架 |
