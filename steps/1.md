# One Punch Bloger——三件套与Web

> 千里之行，始于足下。欢迎来到考核的第一关。

## 关于项目

该项目要求你使用 **HTML + CSS + JavaScript** 构建一个 **自己的个人博客网站** 。

## 学习目标

- 综合运用 HTML、CSS、JavaScript 构建完整的静态页面

- 掌握 CSS 动画、JS 交互、响应式设计、DOM 操作等核心技能

- 构建博客生成器（你可以选择**手搓**，也可以使用**Hexo**等成熟工具辅助生成）

- 培养工程化思维：项目结构、代码规范、部署上线

## 注意事项

我们会把原本完整的代码库挖空，请以填空的形式，逐步学习补全自己的知识库，最终做出自己独一无二的博客。（挖空代码库请在./steps/1/查看）

## 必做功能

**博客首页文章列表展示：** 使用JavaScript动态生成文章卡片，包含标题、发布日期、摘要、标签。至少展示6篇以上文章（可硬编码数据）。

**文章详情页（独立页面）：** 点击首页文章卡片，跳转到独立的post.html页面，通过URL参数（如?id=1）传递文章ID，在详情页根据ID渲染完整内容。

**响应式布局（三端适配）：** 使用 CSS Media Query，按 < 768px / 768px - 1024px / > 1024px 三个区间进行响应式适配，分别对应手机/平板/桌面的展示布局，卡片列数从 1 列 → 2 列 → 3 列自适应变化，文字大小与间距同步调整。

**CSS过渡与悬停交互：** 文章卡片添加悬停效果（上浮/阴影加深/边框变色/过渡时间/下划线/滑入动画…等等），提升用户体验。

**深色/浅色模式切换：** 页面提供切换按钮，点击后切换主题色。使用CSS变量（--bg-color、--text-color等）控制颜色，切换时伴有0.3秒颜色过渡动画。

**导航菜单切换页面：** 点击菜单项按钮后，页面主体内容随之变化的整套交互机制。

**回到顶部按钮：** 页面滚动超过500px时，右下角出现"↑"按钮，点击后平滑滚动回顶部。滚动时按钮渐入渐出。

## 加分项

**文章收藏功能：** 每篇文章卡片上增加「⭐ 收藏/取消收藏」按钮，点击切换状态，收藏数据存入 localStorage。首页增加「全部 / 已收藏」筛选视图，收藏的文章卡片在右上角显示小星标。

**相对时间显示：** 文章发布日期不显示"202x-xx-xx"，而是显示"3天前"、"2小时前"、"刚刚"等相对时间。首页列表和详情页均使用此格式。

**文章搜索高亮：** 搜索结果中，匹配的关键词用黄色背景高亮显示。搜索"CSS"，文章中所有"CSS"文字被标记高亮，替换后保留原始DOM结构。

**标签云：** 首页侧边栏或底部展示标签云，标签字号根据文章数量动态变化（文章越多字号越大）。点击标签筛选对应文章，同时URL带有?tag=xxx参数。

**文章排序切换：** 提供"最新发布"、"阅读量最高"、"标题排序"三种排序方式，点击切换按钮重新排列文章列表。排序状态用下拉菜单或按钮组控制。

**Markdown渲染：** 文章内容使用Markdown格式编写（存储在data中），详情页通过marked.js或自己实现简易解析器，将Markdown转换为HTML渲染。支持标题、列表、链接、代码块、图片等基础语法。

**GitHub Pages部署：** 将项目推送到GitHub仓库，配置GitHub Pages自动部署。提供在线访问链接，并设置自定义域名（可选）。项目README中包含部署链接和构建说明。
