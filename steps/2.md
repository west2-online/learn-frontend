# 中二病也要跨全栈！——React/Vue与TS与Node

> 你所热爱的，就是你的生活。

## 关于项目

该项目要求你运用 **React/Vue + TypeScript + Node.js**，构建一个 **B站鬼畜区数据分析看板**。从爬虫采集、API服务到前端可视化，完成全链路开发。

**前端框架二选一：** 你可以选择 React 或 Vue 完成前端部分，两种框架的学习目标均已列出。

## 学习目标

- 掌握爬虫基本原理，使用axios/cheerio爬取B站鬼畜榜数据
- 运用Node.js + Express搭建RESTful API服务
- 接入大模型API，对视频标题进行鬼畜热梗分类
- 掌握Vite配置（别名、代理、环境变量、代码分割）
- 强化TypeScript类型安全（接口定义、泛型、类型守卫）
- 深入React组件化开发（函数组件、Props、Hooks）
- 掌握React状态管理（useState、useReducer、Context）
- 理解React性能优化（useMemo、useCallback、React.memo）
- 深入Vue组件化开发（组合式API、Props、插槽）
- 掌握Vue响应式原理（ref、reactive、computed、watch）
- 理解Vue生命周期和组合式函数（Composables）

## 注意事项

本项目分为**爬虫服务**、**后端API**、**前端看板**三个独立模块。大模型API需自行申请key（如智谱GLM、讯飞星火、OpenAI等）。**注意，请不要把API key泄露到前端 ~~（被组长发现了就直接拿你的api开蹬）~~**

**前端框架选择：** React 和 Vue 二选一即可，不必同时实现。选择你更熟悉或想挑战的框架。

## 必做功能

**数据爬虫模块：** 使用axios + cheerio爬取B站鬼畜区排行榜视频数据，至少获取视频标题、UP主、播放量、弹幕数、视频链接、封面图等字段。数据定时刷新，存入本地JSON文件或数据库。

**后端API服务：** 使用Express搭建HTTP服务，提供 `/api/videos` 获取视频列表、`/api/video/:id` 获取视频详情、`/api/categories` 获取热梗分类统计等接口。统一错误处理和CORS配置。

**大模型热梗分类：** 接入大模型API，将视频标题传入，让模型判断属于哪个鬼畜热梗类别（如"哲学"、"念诗"、"RAP"、"鬼畜调音"等）。分类结果存入数据中，供前端筛选展示。

**Vite项目配置：** 配置路径别名（如 `@/` 指向 `src/`）、开发环境代理（解决跨域）、环境变量（管理API密钥）、代码分割（按路由/组件懒加载）。

**前端看板主页（React/Vue）：**

- **React版：** 使用函数组件和Hooks构建看板界面，包含数据总览卡片（视频总数、总播放量、分类数量）、视频列表（分页/滚动加载）、分类筛选按钮。所有数据从后端API获取。
- **Vue版：** 使用组合式API和响应式API构建看板界面，包含数据总览卡片（视频总数、总播放量、分类数量）、视频列表（分页/滚动加载）、分类筛选按钮。所有数据从后端API获取。

**视频详情弹窗（React/Vue）：** 点击视频卡片，弹出详情弹窗（Modal），展示完整信息（标题、UP主、播放数据、封面大图、热梗分类）。弹窗支持键盘快捷键关闭（ESC）。

**TypeScript类型安全：** 为所有数据定义接口（Video、Category、APIResponse），API请求/响应使用泛型封装，组件Props使用类型约束。禁止使用any类型。

**环境变量配置与校验：** 前端所有敏感配置（API 地址、密钥等）必须通过 Vite 环境变量注入，源码中零硬编码。同时项目根目录提供 `.env` 文件，列出所有必需的环境变量，应用启动时自动校验关键环境变量是否存在，缺失时构建失败并输出明确错误提示。

## 加分项

**爬虫数据自动刷新：** 后端定时任务（node-cron）每24小时自动执行爬虫，更新数据库中的视频数据。前端页面显示"上次更新时间"。

**ECharts数据可视化：** 使用ECharts在看板中增加图表模块：分类饼图（各类热梗占比）、播放量柱状图（TOP10视频）、趋势折线图（播放量变化）。

**视频详情页爬取：** 爬虫进入每个视频详情页，爬取更详细数据（如视频简介、标签、评论数、投币数等），丰富数据集。

**视频播放器嵌入：** 在视频详情弹窗中嵌入B站视频播放器（iframe或B站API），用户可直接在看板内观看视频。

**API限流：** 后端API增加限流中间件（express-rate-limit），防止爬虫误请求或恶意攻击，保障服务稳定性。

**爬虫数据导出：** 前端提供"导出数据"按钮，将当前视频列表数据导出为CSV或JSON文件，方便离线分析。

**后端 JWT 鉴权：** 后端增加登录接口 `/api/auth/login`，使用固定账号密码，登录成功后返回 JWT Token。所有业务接口必须验证 Token，未携带或无效 Token 返回 401 状态码。前端 axios 实例配置请求拦截器，自动在 `Authorization: Bearer <token>` 头中携带 Token。

**CORS 安全配置：** 后端 CORS 配置不允许使用通配符 `*`，必须显式指定允许的来源（至少包含 `VITE_API_BASE_URL` 对应的前端域名/端口），使用 `cors` 中间件时，配置 `origin` 选项为环境变量中的白名单列表。

**Agent 热梗分析师：** 构建一个 Agent助手，使其能自主调用工具（Tools）搜索B站、获取视频信息、分析弹幕、查询热梗百科/分析一个视频"为什么是鬼畜"，给出理由/对鬼畜区一周趋势生成分析报告。

**多 Agent 协作：** 构建 3 个 Agent（数据采集Agent、分析Agent、报告生成Agent），通过 Agent 间通信完成复杂任务。

**阿里云免费服务器部署（可选）：** 将爬虫+后端API部署到阿里云ECS免费实例（或轻量应用服务器），提供公网API地址供前端调用。
