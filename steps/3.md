# 梗指南——多Agent热点创意工坊

> 冲浪！冲浪！冲浪！

## 关于项目

该项目要求你运用多Agent协作框架、爬虫技术和前端可视化，构建一个热点创意生成工坊。爬虫负责从各大平台采集热点话题与素材，多Agent协作完成"趋势洞察到创意策划再到内容生成"的完整链路，前端看板展示整个创作过程。

## 学习目标

- 综合运用爬虫技能，从多平台采集热点数据
- 理解多Agent系统设计理念，包括角色分工、任务分解和协作通信
- 掌握Agent工具调用机制，即Tool Calling或Function Calling
- 运用大模型实现自主决策与创意生成
- 构建前端创意看板，实时展示Agent工作流与产出
- 理解人在回路（Human-in-the-Loop）设计模式

## 注意事项

本项目分为爬虫模块、洞察Agent、策划Agent、创作Agent和前端看板五个核心模块。大模型API需自行申请key，推荐DeepSeek、智谱GLM或通义千问，便宜大碗。注意，爬虫需遵守各平台的robots.txt，控制请求频率，做个文明的网络公民。

Agent框架选择：LangChain和AutoGen二选一即可，不必同时实现。选择你更熟悉或想挑战的框架。前端部分可以使用React或Vue，但建议保持与任务二一致，任务二用React就用React，用Vue就用Vue，减少切换成本。

## 必做功能

### 一、爬虫模块（素材采集）

选择一个你感兴趣的内容领域，从至少2个平台爬取热点数据。这里提供三种方向，你也可以自选：

社媒热点方向：爬取微博热搜、知乎热榜、抖音热点，获取话题标题、热度值、话题描述

影视番剧方向：爬取豆瓣热门影评、B站番剧评论区，获取短评文本、评分、讨论热度

科技资讯方向：爬取V2EX、Hacker News、36氪，获取帖子标题、点赞数、评论内容

爬取的数据存入本地JSON文件或SQLite数据库，作为Agent的素材库。至少采集100条以上有效数据。

### 二、洞察Agent（趋势分析师）

构建一个洞察Agent，从素材库中识别热点趋势。需调用两个工具：

- get_trending_topics(time_range)：提取当前热度最高的3到5个话题
- analyze_keywords(texts)：对相关文本进行关键词聚类

洞察Agent输出趋势洞察报告，包含热门话题列表、关键词云和趋势判断，推送给策划Agent。

### 三、策划Agent（创意总监）

接收洞察Agent的洞察报告，自主策划创意方向。需调用两个工具：

- generate_angle(topic)：为一个话题生成3个不同的切入角度
- match_format(angle)：根据角度推荐合适的内容形式，如短视频脚本、表情包文案、段子或二创图文等

策划Agent输出创意策划案，包含选定话题、切入角度和内容形式建议，推送给创作Agent。

### 四、创作Agent（内容写手）

接收策划Agent的策划案，生成具体内容。需实现两个创作工具：

- write_script(angle, format)：根据角度和格式生成脚本或文案
- add_humor(text)：在内容中植入网络热梗和幽默元素

创作Agent需支持多轮迭代：生成初稿，自我评价热度潜力评分，修改优化，提交最终版。

### 五、Agent协作编排（SOP引擎）

实现一个编排器（Orchestrator），负责启动和协调三个Agent的工作流：

用户点击开始创作，洞察Agent分析热点，策划Agent出方案，创作Agent写内容，返回结果。

整个流程需有超时控制，单次全流程不超过90秒，超时后编排器记录创意超时并通知前端。

### 六、热点创意看板（React或Vue）

构建一个创意工坊看板，包含以下模块：

热点素材池：展示爬虫采集的热点列表，按热度排序，支持按平台筛选

Agent工作流可视化：以流程图或时间线形式，实时展示三个Agent的协作进度，包括洞察中、策划中、创作中和已完成

创意产出展示区：展示最终生成的创意内容，如短视频脚本、文案或段子等，支持一键复制

迭代记录：展示创作Agent的版本迭代过程，包括V1初稿、V2优化和V3定稿，每版附带自评分

### 七、工具调用标准化

所有Agent的工具调用必须遵循统一规范：

定义Tool接口，包含name、description和parameters JSON Schema

工具执行结果返回ToolResult，包含success、data和error字段

三个Agent各拥有至少2个工具

### 八、数据持久化与历史查询

所有爬虫数据、洞察报告、策划案和创作内容存储到SQLite数据库

前端看板提供创意档案页面，按时间、话题和内容形式筛选查看历史产出

### 九、环境变量与配置校验

所有敏感配置，包括API Key和数据库路径，通过环境变量注入，源码零硬编码。项目启动时自动校验关键环境变量是否存在，缺失时输出明确错误提示并终止启动。

## 加分项

Agent思维链可视化：在前端看板中，以脑暴黑板形式展示Agent的决策过程。例如策划Agent显示：话题AI取代人类，角度1反讽调侃太老套，角度2职场黑色幽默匹配当前热点，推荐形式短视频脚本。用卡片流或树形结构渲染。

Agent对话日志与回放：记录所有Agent间的通信消息，存入数据库。前端提供对话回放功能，可重现一次创意全过程的Agent对话。

素材自动更新：爬虫模块支持定时任务，如使用node-cron或schedule，每6小时自动爬取最新热点，保持素材库新鲜度。前端显示素材库更新时间。

自定义创作模板：用户可在前端自定义创作参数，包括风格偏好如沙雕、深情或反讽，内容长度如短、中或长，平台适配如抖音、B站或小红书，Agent根据参数调整输出风格。

多格式导出：创意内容支持导出为多种格式，包括纯文本、Markdown、视频脚本分镜表（表格格式）和社交媒体发帖文案（带话题标签）。

人类反馈强化：用户可对Agent产出的创意进行1到5星评分和文字反馈，系统记录反馈数据，Agent在后续创作中参考历史评分偏好的风格。

素材溯源：每个创意产出都标注灵感来源，关联到具体的热点素材，例如灵感来源：微博热搜话题XXX，日期为2026年9月2日，让创意有据可查。

阿里云或腾讯云免费服务器部署（可选）：将多Agent系统部署到云服务器，提供公网访问地址。前端看板部署到云存储或Vercel，形成完整可演示的线上Demo。

# RN三姐妹——React Native与TS进阶

> 摸鱼一时爽，摸鱼一直爽。

## 关于项目

该项目要求你使用 **React Native + TypeScript** 开发一个「**摸鱼养鱼**」手机App，最终生成APK安装包并装到自己手机上。

## 学习目标

- 掌握React Native跨平台开发（组件、样式、导航）
- 使用TypeScript保障类型安全
- 实现核心游戏循环（点击累积、解锁机制）
- 处理本地数据持久化（AsyncStorage）
- 学习APK打包与真机调试
- 理解移动端交互特点（触控反馈、手势）

## 注意事项

真机调试需点击手机版本号7下进入开发者模式，开启USB调试；之后连接数据线，选择允许传输文件。打包APK需要下载Android Studio，以及在 Android Studio 内配置 SDK , NDK 。

## 必做功能

**使用Expo构建项目：** 使用 `npx create-expo-app --template` 创建项目，采用 Development Build 模式开发，禁止使用 Expo Go 运行。

**APK 本地打包：** 使用 `npx expo run:android` 生成 debug APK 或 Android Studio 构建 release APK，提供完整的本地打包步骤文档。

**鱼缸主界面：** 展示一个"鱼缸"背景，包含当前鱼种、摸鱼值（数字显示）、鱼的数量或状态。背景有动态水波纹或气泡动画（CSS动画或Lottie）。

**点击摸鱼交互：** 用户点击"摸鱼"按钮，触发点击动画（按钮缩放/水花特效），摸鱼值+1（或按当前收益增加）。点击时有触感反馈（Vibration）。

**摸鱼值累积与升级：** 摸鱼值达到特定阈值（如10、50、200、1000）时，自动解锁新鱼种或新成就。解锁时弹出庆祝动画/通知。鱼缸中的鱼会随之变化。

**鱼种/成就图鉴：** 提供一个"图鉴"页面，展示所有鱼种和成就的解锁状态（已解锁/未解锁）。已解锁的鱼种展示精美图标和名称。

**数据持久化：** 使用AsyncStorage本地保存摸鱼值、已解锁鱼种/成就、总点击次数等所有游戏数据。App冷启动时自动加载存档。

**设置页面与重置：** 提供设置页面，包含"重置游戏"按钮（二次确认弹窗），重置所有数据回到初始状态。可开关音效或震动反馈。

**接入 Agent 能力**：App 内嵌入一个“AI 养鱼顾问” Agent，能回答用户关于养鱼的问题、推荐鱼种搭配、预测升级所需时间

## 加分项

**腾讯云开发（TCB）云端数据同步：** 使用腾讯云开发匿名登录 + 云数据库，将摸鱼值、已解锁鱼种/成就、总点击次数按 `openid` 隔离存储，App 冷启动时云端数据优先于本地 AsyncStorage。

**腾讯云开发环境配置文档：** 在 README 中完整写出从注册腾讯云账号、创建环境、获取环境 ID、配置 `.env` 到初始化数据库集合的全步骤。

**用户认证：** 集成手机号或邮箱登录（可使用Firebase Auth或自建服务），登录后数据可云端同步。

**实时排行榜：** 基于云端数据，展示全球或好友的摸鱼值排行榜（每日/每周/总榜），激励用户持续点击。

**上传头像：** 用户可自定义头像（从相册选择或拍照），在排行榜和好友列表中显示。

**云同步状态 UI：** 主界面顶部展示「已同步 / 同步中 / 未同步」三种状态，提供「立即同步」手动按钮及重试机制。
